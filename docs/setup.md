# セットアップ（新しいPCで使う）

## 動作条件

- Node.js 22.16以上（`node:sqlite` が利用できること）
- 開発/導入時に npm パッケージを取得できるインターネット接続
- 会計用のPC、必要なタブレット、同じネットワークで端末間通信できるWi-Fi

## 1. 準備（Windows：ダブルクリックでOK）

1. Node.js 22.16以降（npm同梱）をインストールします。まだなら <https://nodejs.org/> から入手。
2. ZIPをダウンロードした場合は **すべて展開** して、`package.json`、`setup.cmd`、`start.cmd` が並ぶフォルダを開きます。ZIPの中から直接実行しないでください。
3. **初回のみ `setup.cmd` をダブルクリック**。必要なパッケージをインターネットから取得して、`dist/` に画面を作ります。失敗時は画面に原因を表示します。
4. **`start.cmd` をダブルクリック**。2回目以降はこれだけで起動できます。セットアップを忘れて `start.cmd` を使ったときは、必要なファイルがなければ自動セットアップを試みます。
5. 初回起動時に生成された **`data/initial-access.json` の管理PINと端末登録コードを責任者だけが保管**。
6. PCで `http://localhost:3000/admin` を開いて管理PINでログイン。商品価格・在庫・販売状態を確認／調整。
7. `http://localhost:3000/staff` と `http://<PCのLAN IP>:3000/kitchen` で各端末を登録。お客さんの注文用は `/` を開く。

**開発者向け**：コマンドラインでは `npm ci` → `npm run build` → `npm test` → `npm start` を使用します。`setup.cmd` が行うのはインストールとビルドです（テストは別途手動）。

## 2. 店舗端末への配布

同じWi-Fi上ならタブレットでは、PCの起動ログに出るLAN内IPとポート3000を使用。タブレットの `localhost` は**タブレット自身**を指すため使用不可です。

Windowsファイアウォールは、信頼できるプライベートネットワークでTCP 3000だけ必要な範囲に許可してください。**ルーターのポート開放やインターネットへの一般公開はしない**でください。

## 4. 維持管理

停止するときはサーバーコンソールで `Ctrl+C`。同じDBに対してサーバーを二重起動しないでください。実データを誤ってGitに追加しないよう `data/` と `backups/` は除外しています。

`data/` には管理用認証情報と運用DBが生成されるため、**SNS、GitHub、共有フォルダにアップロードしないでください。**
