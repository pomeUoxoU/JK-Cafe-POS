# JK-Cafe POS

2026年の高専祭で、パンケーキ屋台「JK-Cafe」の注文と会計に使ったシステムです。お客さんがタブレットでシロップやトッピングを選ぶと、レジに受付番号と金額が表示されます。スタッフが現金を受け取り、入金を確定した注文だけがキッチンに届きます。

高専祭の2日間で約244食（初日約123食、2日目約121食）を販売し、収入は95,640円でした。雨だった2日目は15時半に完売しました。これらは屋台全体の実績です。当日の注文履歴や会計データは含めていません。

## 屋台での使い方

WindowsノートPCでサーバーとレジを動かし、同じWi-FiにつないだAndroidタブレット2台を注文用と調理用に使います。営業中はインターネット接続がなくても動きます。PCとタブレットの間のWi-Fi接続は必要です。

| 開く端末 | 画面 | 主な操作 |
| --- | --- | --- |
| 注文用タブレット | `/` | 皿ごとにトッピングを選び、完成イメージと合計を確認して注文する |
| レジのPC | `/staff` | 受付番号を照合し、クーポンの提示と現金の受け取りを確認する。訂正・返金もここで行う |
| 調理用タブレット | `/kitchen` | 皿ごとの内容を見て、調理開始・完了・受け渡しを記録する |
| 管理者のPC | `/admin` | 価格と在庫の変更、売上の確認、経費の記録、レジ締め、CSV出力 |

未払いの注文は売上に含めません。注文時に材料を取り置きし、入金前に注文が失効すると在庫に戻します。

## Windowsで起動する

1. [Node.js](https://nodejs.org/)（22.16以降、npm同梱）をインストールします。
2. このリポジトリのZIPをすべて展開し、初回は `setup.cmd` をダブルクリックします。パッケージの取得にはインターネット接続が必要です。
3. `start.cmd` をダブルクリックします。営業が終わるまで、このウィンドウは開いたままにします。

PCのレジ画面は [localhost:3000/staff](http://localhost:3000/staff) です。タブレットでは、起動時に表示されるPCのLANアドレスを使います。注文用はそのまま、調理用は末尾に `/kitchen` を付けて開きます。

初回起動時の管理者PINと端末登録コードは `data/initial-access.json` に保存されます。レジと調理端末を登録し、営業前に管理画面で価格と在庫を確認してください。認証情報を含む `data/` とバックアップは共有しないでください。サーバーは店内のLANで使い、インターネットには公開しません。

## 開発

画面はReactとTypeScript、サーバーはNode.jsとExpressです。注文・会計・在庫はPC上のSQLiteに保存し、画面間の通知にはSocket.IOを使います。

```sh
npm ci
npm run build
npm test
npm start
```
