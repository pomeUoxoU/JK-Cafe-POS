# 🥞 JK-Cafe POS

**高専祭で実際に使った、パンケーキ屋台のためのセルフ注文・会計・調理管理システム。**

お客さんがタブレットでパンケーキをカスタマイズし、スタッフが現金会計をすると、キッチンに調理指示が届きます。商品・トッピングの在庫、注文の訂正、売上集計、精算もひとつにまとめました。淡いピンクを基調とした注文画面と、トッピングに連動する完成イメージが特徴です。

> **JK-Cafe 2026 保存版** — 2026年の高専祭で使用したパンケーキ専用版を、デザイン・注文ルールごと残すためのリポジトリです。ほかの屋台向けに汎用化する開発は、別プロジェクトで行う構想です。

## 🎀 高専祭での実績

| 項目 | 2026年高専祭での実績 |
| --- | ---: |
| 2日間の収入 | **95,640円** |
| 販売数 | **約244食**（初日約123食、2日目約121食） |
| 2日目の完売時刻 | **15:30** |

2日目は雨天。材料・アイスの補充待ちも発生しましたが、販売分は完売しました。上記はイベント全体の実績であり、同梱のソフトウェアが計測・検証した数値ではありません。**実際の売上・注文履歴を含む運用データは、本リポジトリには収録していません。**

## ✨ できること

- **セルフ注文**：商品 → シロップ → 基本トッピング → 追加トッピング → 確認。複数皿の組み合わせ、クーポン、在庫確認に対応。
- **かわいいプレビュー**：選択内容に応じてソース・ホイップ・アイス・スプレー・クッキー片を合成表示。
- **現金会計**：預かり金、お釣り、クーポン確認、入金前後の注文管理。
- **キッチン連携**：支払いが確定した注文を調理画面へ通知。調理中・完了・受け渡しまで追跡。
- **運営管理**：商品価格と在庫、注文訂正・取消・返金、経費、日別売上・概算利益、現金締め。
- **保全**：CSV書き出し、DBバックアップ、端末登録、管理者認証。

## 📱 画面と運用

| 画面 | パス | 用途 |
| --- | --- | --- |
| お客さん | `/` | 注文・カスタマイズ |
| レジスタッフ | `/staff` | 現金会計・注文訂正 |
| 調理スタッフ | `/kitchen` | 調理・提供状況管理 |
| 管理者 | `/admin` | 商品・在庫・売上・端末設定 |

通常は **Windows PC 1台でNode.jsサーバーを動かし、同じWi-Fiに接続したタブレットで利用**します。いちど必要なパッケージを準備すれば、営業中のインターネット接続は不要です。ただしPCと各端末間のLAN通信は必要で、各端末だけで独立して会計できるオフラインPOSではありません。

## 🚀 はじめかた

**Windowsならコマンド入力なしで準備できます。** まず [Node.js 22.16以降](https://nodejs.org/)（npm同梱）をインストールしてください。

1. このリポジトリをダウンロードして **ZIPをすべて展開**（ZIPを開いたまま実行しない）。
2. 初回だけ `setup.cmd` をダブルクリック。必要なパッケージを取得して画面をビルドします（**インターネット接続が必要**）。
3. `start.cmd` をダブルクリックして起動。次回以降は `start.cmd` だけでOK！
4. `setup.cmd` を忘れて `start.cmd` を開いても、必要なファイルがなければ自動で初回セットアップを試みます。

起動したPCで `http://localhost:3000/` を開いてください。同じWi-Fi上のタブレットでは起動ログに表示されるPCのLAN内IPとポート3000を使います。**サーバーの黒い画面は営業時間中ずっと開いておいてください。**

開発者向けの手動操作は以下です。

```bash
npm ci
npm run build
npm test
npm start
```

`node_modules/` と `dist/` はZIP・GitHubに含めず、`setup.cmd` で各PCに生成します。`npm ci` やビルドに失敗したときは [トラブルシューティング](docs/troubleshooting.md) を見てください。2026年11月、利用者のWindows PCで簡単起動版が動いたとの報告を受けています。別PCや実際の営業では改めて動作確認してください。

**初回起動時の管理者PIN・端末登録コード**は、実行したPC上の `data/initial-access.json` に自動生成されます。**このファイルを公開・共有・スクリーンショット掲載しないでください。** 初期データはデモ/検証用です。イベント前に価格・販売状態・在庫を確認してください。

詳しくは [セットアップ](docs/setup.md)、[当日運用](docs/operation.md)を参照してください。

## 🔐 セキュリティ・公開範囲

このリポジトリは**ソースコードと表示素材**を共有するためのものです。次のデータは含めません：実際の注文/売上DB、管理PIN/端末登録コード、端末認証情報、バックアップ、過去のGit履歴、依存パッケージ、ビルド成果物。

- 本システムは**信頼できるローカルネットワークでの利用**を想定しています。インターネットに直接ポートを開放しないでください。
- GitHub Pagesなどの静的ホスティングだけでは動作しません。Node.jsとSQLiteを扱うサーバーが必要です。
- 公開用データは空のDBから自動生成します。実運用前には会計、訂正、返金、在庫、ネットワーク障害、バックアップ復元を再テストしてください。
